#  Tumise Graphix: Email server
---

## 📖 Overview
An automated lead generation engine built with **Flask**. 
*Designed to engage clients while the backend handles the heavy lifting.*

## 🛠️ Tech Stack
- **Backend:** Python / Flask
- **Security:** SMTP_SSL (Encrypted)
- **UI:** Glassmorphism Success Page

## ⚡ Key Features
1. **Auto-Mail:** Sends formatted briefs to the CEO instantly.
2. **Client Retention:** Interactive JS slider on the success page.
3. **Ghost Mode:** Auto-closing tabs after process completion.
